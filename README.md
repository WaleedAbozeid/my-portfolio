# portfolio

A Flutter portfolio web application.

## 🚀 Live Demo


The application is automatically deployed to GitHub Pages. After enabling GitHub Pages in your repository settings, your app will be available at:

**If this is a project repository:**
- `https://YOUR_USERNAME.github.io/portfolio/`

**If this is a user/organization page repository:**
- `https://YOUR_USERNAME.github.io/`

## 📋 Setup GitHub Pages

1. Go to your repository on GitHub
2. Click on **Settings** → **Pages**
3. Under **Source**, select:
   - **Source**: `Deploy from a branch`
   - **Branch**: `gh-pages` → `/ (root)`
4. Click **Save**
5. The workflow will automatically deploy your app when you push to `main` or `master` branch
6. After the first deployment, your site will be available at the URL shown in the Pages settings

## 🔄 Automatic Deployment

The app is automatically deployed using GitHub Actions whenever you:
- Push code to the `main` or `master` branch
- Manually trigger the workflow from the Actions tab
